Destination rows and local tabs accept internal copy/move and external copy. Same-window file drags can switch to a destination tab after dwelling, and the native timer checks the drag identity before switching. |
| Name forms | Rename, New Folder, and paste conflicts share the native single-line field, select the suggestion on mount, and use localized validation labels.
