# Files common components and secondary pages

The comparison uses GDS `5fc77a8` and gpui-kit `f61ebe1b` as the reference. The original Settings and Help captures are under `target/files-e2e/gpui-5fc77a8-pages-np6915yl`. The matching compact candidate scenes are under `target/files-e2e/parity-scenes-y_s_7mzz` and the integrated interaction runs cover the final changes.

| Area | Reference and migration changes |
| --- | --- |
| Frame and interaction | Toolbar, workspace and footer use a shared 160 ms sidebar sample. Navigation text fades without affecting the primary icons. Shared region focus outlines, disclosure artwork and a focusable 9 px divider restore the anatomical controls. Arrow Up and Down resize focused dividers by 12 px and store the same preference as a pointer drag. |
| Settings | All six pages retain their original order and grouped form rows. Theme source and palette selection are separate, with search aliases, an unavailable System option and conditional built-in/custom fields. The Extensions page automatically checks the configured Baloo commands, refreshes when commands change and allows a previously enabled backend to be disabled even if detection fails. Terminal controls follow the terminal enable switch. Performance shows the original explicit unlock and whole-form reset. Settings restores focus when an unlocked or reset control disappears. |
| Help and About | Help uses the command metadata and individual keycaps, including the dialog decision strokes and tab range. About uses the app mark, version and build tag, selectable values, copy controls and website links. Credits and License return to Overview with Escape or Alt+Left. |
| Dialogs | The shared alert uses the original top inset, 250 ms slide curve and dark/light backdrop alpha from the pinned Kit theme. Alert backdrop clicks remain blocked. Cancel and confirm use Alt+C and Alt+A where the primary action is registered. Held keytips sit beside the decision buttons so the labels stay readable. The controls and scrollable content stay inside compact windows. |
| Notifications | The overlay retains persistent failures, scrolls the selected card into view, and supports Up, Down, Home, End and Escape. Its cards enter in 400 ms and leave in 200 ms. Cards use the original 24 px copy control and 20 px close control revealed on hover. Alt+N remembers the exact focused control and returns to it when it remains visible and enabled. The owning Files or Settings region serves as fallback. |
| Terminal | Dock reveal and maximize use the same 160 ms workspace policy. The split maintains the stored preferred height across window constraints. Clicking session rows keeps focus in the session list. Up, Down and Enter select and enter a session, and Ctrl+N, Ctrl+W, F2 and F6 reach the original session actions. Middle-click and the compact corner control close a session. Closing the active session advances to its neighbor. Hiding the surface preserves the PTY, and the directory action starts a new tab at the requested directory without modifying an existing shell's line. |
| Debug | An opt-in, independent native window hosts the existing log Store and task registry. Reopening reuses it, refocuses the current panel, and requests activation from the originating Wayland input. Logs restore UTC millisecond timestamps, level, tracing target, message preview, selectable full detail, target/level/text filters, and Up/Down/PageUp/PageDown navigation. Tasks restores expandable scopes, identifiers, status, execution, age and source. Ctrl+W closes this window. |

## Evidence

- The original and candidate compact settings captures show the same Settings destinations and restored theme, extensions and unlock controls. The File browsing auto-focus switches differ because the original capture fixture supplies `auto_focus_search = true` and the candidate fixture supplies `false`. Both source defaults are `false`.
- The isolated diagnostics probe mounted the actual window created by `ui::logs::open` as a separate native `Ui`. It drove type-to-filter, level and target selection, row navigation and detail, task scope collapse and expansion, tab state, close/reopen, and reuse of an open window. ## Supported differences and unverified cases

- The native keytips are positioned with their controls, using the window's Ctrl/Alt state and availability, and suppress hidden controls. The original global badge packer can move labels around nearby controls or stack multiple labels in bounded trailing space. Native local placement can still overlap groups in some compact states.
- Wayland chooses placement and whether to honor an activation token. The native diagnostics window supplies the original initial size and uses the compositor's top-level placement. AntiWebUI's two-connection protocol test verifies issuance and routing of activation tokens.
- Backend detection in the compact fixture exercises the unavailable Baloo path. Successful tag checks and the selection of user-installed palettes still depend on a prepared desktop or temporary configuration fixture. The matching compact screenshots do not establish behavior on every installed theme or mouse compositor configuration.
