# Theme demo wallpaper sources

`theme-sync.gif` contains 16 real desktop captures in English and light mode, with a fixed
GDS Files window and a different wallpaper and desktop palette in each frame.
It loops every 16 seconds at 960 × 622 pixels. The captures use the host DMS
system palette and the current light mode. See [capture.md](capture.md) for the
recording scripts; the original desktop wallpaper is restored after recording.

Wallpaper artwork belongs to its respective creators. The following links
identify the online collections used for this recording.

`file-browsing.gif` also shows thumbnails of the Mojave, Bliss and Big Sur
wallpapers listed below. Its preview copies are resized to fit within
2560 × 1440 pixels. The other captures also use Big Sur as their backdrop. All screenshots and GIFs
use the English interface; `terminal.png` shows fastfetch in the built-in terminal.
