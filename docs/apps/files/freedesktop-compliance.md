# GDS Files — Linux Open Desktop (FreeDesktop / XDG) Compliance Review

[简体中文](i18n/zh-CN/freedesktop-compliance.md)

- **Scope**: `bin/files/`, `src/service/` (`desktop`, `file_inspection`, `file_tags`, `remote`, `storage`, `window_id`), `bin/portal/`, `assets/files/`, `packaging/`
- **Baseline**: Audited against `9c30e63`; all 15 defects (`D-01`–`D-15`) resolved on `main` (2026-11-28)
- **Classification Policy**: Findings are separated into two tracks so cross-desktop standards ship first while desktop-environment-specific conventions remain opt-in:
  1. **Universal Open Desktop Standards (Primary Track)**: Formal FreeDesktop / XDG / Wayland / UDisks2 / IETF specifications (and cross-application guidelines) independent of any single desktop environment. Covers **15 resolved implementation defects (`D-01`–`D-15`)** and **5 unimplemented standard capabilities (`G-01`–`G-05`)**.
  2. **Desktop / Toolkit Dialects (Backlog)**: Informal conventions, private metadata formats, or divergent extensions originating in GTK/GNOME/GVfs, KDE/KIO/Dolphin, or XFCE. Covers **5 items (`DE-01`–`DE-05`)**.

GDS Files implements core Linux Open Desktop specifications natively (`org.freedesktop.Application`, `org.freedesktop.FileManager1`, `org.freedesktop.impl.portal.FileChooser`, `shared-mime-info` / `mime.cache` v1.2, FreeDesktop Trash 1.0, Thumbnail Cache & external `.thumbnailer`, `recently-used.xbel`, `org.freedesktop.secrets`, `user.mime_type`/`user.xdg.tags`/`comment`/`origin.url`, `xdg-user-dirs`, and `XDG_TEMPLATES_DIR`).

## 2. Resolved Defects Details (`D-01`–`D-15`)

### Phase 1 (P1 — Critical Compliance & Interoperability)

- **D-01 (`recently-used.xbel`)**: Rewrote XBEL updates in [recent_files.rs](../../../src/service/desktop/recent_files.rs) around `DocumentEnvelope` to preserve root attributes, foreign `xmlns:*` prefixes, and non-`<bookmark>` elements; handled self-closing `<bookmark .../>`, `<info/>`, `<metadata/>`, and `<bookmark:applications/>`; changed `clear_at` to retain `<bookmark:private/>` and non-`file://` bookmarks; added cross-process `flock` serialization via `<xbel>.lock` (`O_NOFOLLOW | O_CLOEXEC`, mode `0o600`).
- **D-02 (`OpenURI` / `Inhibit` / Secret Service portal context)**: Updated [client.rs](../../../src/service/desktop/client.rs) to open portal descriptors `O_RDWR` (falling back to `O_RDONLY` on read-only/busy/directory paths) and forward `writable` to `OpenFileRequest::writeable(...)` in [portal.rs](../../../src/service/desktop/portal.rs). Added feature-isolated [window_id.rs](../../../src/service/window_id.rs) (`ParentWindow`) and `OpenContext` plumbed through `Desktop::open_file_with_context`, `InhibitGuard::delayed_with_window` ([session.rs](../../../src/service/desktop/session.rs)), and `keyring::{lookup,store,delete}_with_window` ([keyring.rs](../../../src/service/remote/keyring.rs)).
  - **Upstream prerequisite**: Exporting live `zxdg_exporter_v2` handles and requesting outgoing `xdg_activation_v1` tokens from the active UI window awaits adding those methods to `WindowHandle` in `GanDesktop/zgui`.
- **D-03 (Executable `+x` gate)**: Added [executable.rs](../../../src/service/desktop/executable.rs) (`ExecutableClassifier`) combining header checks (`#!`, `\x7fELF`, `[Desktop Entry]`, executable `infer` MIME types while excluding `.pem`/`.der`), Linux `user.mime_type`, and XDG `shared-mime-info` (`globs2`/`globs`, `aliases`, `subclasses`). Non-executable `0755` documents (`.pdf`, `.txt`, `.md`, `.svg`, `.docx`, `.html`) on FAT/NTFS/SMB volumes now open directly while binaries, scripts, and disguised files still require the chooser.
- **D-04 (`user.mime_type` in directory browsing)**: Added stack-buffered `lookup_mime_type` (`XattrLookup`) in [file_tags.rs](../../../src/service/file_tags.rs) and `classify_file_base` in [content.rs](../../../bin/files/src/entities/file/api/directory/content.rs), wired into `read_directory_base`, `inspect_base_with_identities`, and `LinkTarget::from_path_base` ([directory.rs](../../../bin/files/src/entities/file/api/directory.rs)) with per-directory `EOPNOTSUPP`/`ENOSYS` short-circuiting so unique-extension files honor `user.mime_type` without triggering 8 KiB header reads.
- **D-05 (Secret Service collection unlock)**: Updated unsandboxed `lookup()` in [keyring.rs](../../../src/service/remote/keyring.rs) to check `collection.is_locked()` and unlock the default collection before calling `search_items` (surfacing `Error::Dismissed` if cancelled), matching `store()`/`delete()` and removing the implicit GNOME Keyring assumption while keeping `has_saved()` passive.

### Phase 2 (P2 — Specification Alignment)

- **D-06 (XDG Base Directory relative paths)**: Added pure XDG path resolvers filtering relative `XDG_DATA_HOME` and `XDG_DATA_DIRS` with spec fallbacks in [mime_db.rs](../../../bin/files/src/entities/file/api/directory/content/mime_db.rs) and [external.rs](../../../src/service/file_inspection/thumbnail/external.rs).
- **D-07 (Shared MIME-Info & `mime.cache` v1.2)**: Classified unmatched 0-byte files as `application/x-zerosize` (`ContentCategory::Text`, text-previewable via [mime-types.toml](../../../bin/files/src/entities/file/api/directory/content/assets/mime-types.toml)); added binary `mime.cache` v1.2 `NamespaceList` / `IconsList` and plain-text `XMLnamespaces` / `icons` parsing with bounded 8 KiB XML root refinement; enforced cross-layer `<glob-deleteall/>` (`0:<mime>:__NOGLOBS__`) suppression without matching literal `__NOGLOBS__` filenames.
- **D-08 (Trash 1.0 `directorysizes` & live watching)**: Added [directory_sizes.rs](../../../bin/files/src/features/file_operations/recycle/directory_sizes.rs) for byte-safe `directorysizes` parsing (matching `.trashinfo` mtime seconds on list) and atomic temp-file + rename pruning on directory `restore` and `purge`; added [watch.rs](../../../bin/files/src/features/file_operations/recycle/watch.rs) (`TrashWatch`) wired into [tabs.rs](../../../bin/files/src/pages/workspace/navigation/tabs.rs) for debounced live refreshes across home and active local mount trash `info/` directories.
- **D-09 (Thumbnail Managing Standard)**: Stopped persisting `Error::NoCover` / missing external thumbnailer to `fail/` and ignored legacy `no-cover` markers; resolved symlinked cache roots in `Cache::contains`; added bounded, symlink-safe `ThumbnailInvalidation` wired into delete, trash, rename, move, and undo/redo ([api.rs](../../../bin/files/src/features/file_operations/api.rs), [rename.rs](../../../bin/files/src/features/file_operations/api/rename.rs), [transfer.rs](../../../bin/files/src/features/file_operations/transfer.rs), [history.rs](../../../bin/files/src/features/file_operations/history.rs)); added read-only `.sh_thumbnails/` lookup and user-cache `large`/`normal` fallback on generation failure.
- **D-10 (`mime_apps.rs`)**: Deleted unused `src/service/desktop/mime_apps.rs` and removed its re-export from [desktop.rs](../../../src/service/desktop.rs); application selection stays delegated to XDG portals.
- **D-11 (RFC 8089 local hostname `file://` URIs)**: Added cached local-hostname matching (`parse_local_file_uri_with_host` / `parse_strict_local_file_url_with_host`) in [recent_files.rs](../../../src/service/desktop/recent_files.rs) and shared it across clipboard/DnD ([protocol.rs](../../../bin/files/src/shared/lib/clipboard/protocol.rs)), `FileScheme` ([scheme.rs](../../../bin/files/src/entities/location/scheme.rs)), and `FileManager1` ([file_manager.rs](../../../src/service/desktop/file_manager.rs)).
- **D-12 (`org.freedesktop.FileManager1`)**: Allowed `ShowFolders` to validate and route supported network (`smb://`, `sftp://`) and GDS virtual URIs via `scheme::parse`; isolated `ShowItemProperties` ([browser.rs](../../../bin/files/src/pages/workspace/shell/browser.rs), [windows.rs](../../../bin/files/src/app/windows.rs), [details.rs](../../../bin/files/src/pages/workspace/panes/inspection/details.rs)) to open only standalone `Properties` windows with activation tokens without switching tabs, mutating persisted `details`, or spawning a main browser window.

### Phase 3 (P3 — Activation, Packaging Metadata & Dynamic User Dirs)

- **D-13 (`org.freedesktop.Application` & `DBusActivatable=true`)**: Registered `org.freedesktop.Application` (`Activate`, `Open`, `ActivateAction("new-window")`) at `/io/github/GanDesktop/GdsFiles` in [file_manager.rs](../../../src/service/desktop/file_manager.rs), wired `Request::Activate { new_window }` in [windows.rs](../../../bin/files/src/app/windows.rs) and [browser.rs](../../../bin/files/src/pages/workspace/shell/browser.rs), and enabled `DBusActivatable=true` + `io.github.GanDesktop.GdsFiles.service` across [install.py](../../../packaging/linux/install.py), [gds.spec](../../../packaging/fedora/gds.spec), [gds-files.install](../../../packaging/debian/gds-files.install), [package.nix](../../../packaging/nix/apps/files/package.nix), and [module.nix](../../../packaging/nix/apps/files/module.nix).
- **D-14 (AppStream MetaInfo)**: Updated [io.github.GanDesktop.GdsFiles.metainfo.xml](../../../assets/files/io.github.GanDesktop.GdsFiles.metainfo.xml) with `<categories>`, localized `<keywords>`, `<provides>` (`<binary>gds-files</binary>`, `<dbus type="user">` for both bus names), and lowercase `<developer id="io.github.gandesktop">`. Verified zero errors and zero warnings with `appstreamcli validate --no-net`. `<screenshots>` remains deferred until hosted release screenshots exist.
- **D-15 (Dynamic XDG User Dirs)**: Added pure `user-dirs.dirs` parsing and slot-tracked reconciliation in [user_dirs.rs](../../../bin/files/src/entities/location/api/places/user_dirs.rs), [places.rs](../../../bin/files/src/entities/location/api/places.rs), and [accessor.rs](../../../bin/files/src/entities/location/api/places/accessor.rs) using existing `places_meta` (`xdg_user_dirs_snapshot`), preserving user order and explicit removals while updating relocated XDG directories in place; added live `user-dirs.dirs` watching in [entities/location/places.rs](../../../bin/files/src/entities/location/places.rs) subscribed per window via `Context::bind_places_sync` ([context.rs](../../../bin/files/src/pages/workspace/state/context.rs), [browser.rs](../../../bin/files/src/pages/workspace/shell/browser.rs)).

## 3. Existing Peripheral Dialect Compatibility Layers (Boundary Reference)

GDS Files already carries a small, deliberate set of peripheral dialect adapters outside the universal core:

- **Clipboard copy/cut dialects**: [protocol.rs](../../../bin/files/src/shared/lib/clipboard/protocol.rs) reads and writes GNOME `x-special/gnome-copied-files` and KDE `application/x-kde-cutselection` alongside `text/uri-list`.
- **`.hidden` file lists**: Originated in GLib/Nautilus and widely adopted across file managers; honored during local directory listings.
- **KDE Baloo / KIO tag index bridge**: Documented with explicit trade-offs and retirement criteria in [External Tool Integrations](../../decisions/external-integrations.md).
