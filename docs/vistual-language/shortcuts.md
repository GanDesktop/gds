# GDS 快捷键与键帽

本文是整个套件的**默认绑定、显示方式与焦点规则**的集中定义，；各应用采用同一呈现、焦点和相同语义动作的默认键位；具体动作集合与应用作用域由各应用自己维护。设置通过主页面左上菜单或 `Ctrl+,` 进入；设置以左上 ArrowLeft 返回工作区；最近、收藏等位置沿用页签导航，没有底部设置按钮或右上返回 X。公共视觉基线见 [视觉语言](README.md)，即时应用规则见 [设置中心](../settings/README.md)。


## 1. 同一语义，同一绑定

相似动作在不同应用、同一应用的不同位置采用相同默认绑定。动作的作用对象由明确的 scope 与当前焦点决定，不由鼠标悬停位置偷偷改变。

新增常用应用指令优先使用 `Ctrl+字母`，同组反向或扩展动作使用 `Ctrl+Shift+字母`；字母统一按英文动作语义助记，切换界面语言时保持绑定。Alt 主要用于位置导航与明确的界面访问键，页面专属动作通过作用域限制。沿用既有操作习惯，低频动作可通过键盘打开上下文菜单访问，不要求每个按钮都有独立组合。

### 五个核心动作

| 语义 action ID | 动作 | 默认键帽 | 作用域 |
| --- | --- | --- | --- |
| `settings.open` | 打开 / 聚焦完整设置中心 | <kbd>Ctrl</kbd> <kbd>,</kbd> | 显式窗口级 |
| `tab.new` | 新建页签 | <kbd>Ctrl</kbd> <kbd>N</kbd> | 当前文件工作区，或聚焦的终端半区 |
| `tab.close` | 关闭当前页签 | <kbd>Ctrl</kbd> <kbd>W</kbd> | 当前文件工作区，或聚焦的终端半区；内置终端直接终止并等待清理 |
| `panel.terminal` | 显示 / 收起终端 | <kbd>Ctrl</kbd> <kbd>`</kbd> | 显式窗口级，作用于整个终端 dock |
| `panel.sidebar` | 展开 / 折叠侧栏 | <kbd>Ctrl</kbd> <kbd>B</kbd> | 具有侧栏的当前应用界面；不覆盖终端文本输入 |

新建页签使用 **Ctrl+N**。`tab.new` 和 `tab.close` 在不同页签栏复用语义，但必须解析到相应的文件或终端目标。

### 区域访问与通知

Alt 作为套件统一的界面访问修饰键：同名区域在不同应用中使用相同默认键，不随语言变化。访问键只转移焦点，不打开位置、不切换当前标签、不改变中央表区的选择；区域内用上下键移动键盘光标，Enter 才打开目标。Ctrl 继续用于内容操作，`Ctrl+L` 保留为编辑地址栏。

| 动作 | 默认键帽 | 作用域 |
| --- | --- | --- |
| 聚焦位置组 | `Alt+L` | 文件工作区的侧栏位置组 |
| 聚焦卷组 | `Alt+V` | 侧栏卷组；隐藏时在本会话临时显示，折叠时展开 |
| 聚焦标签页组 | `Alt+T` | 侧栏标签页组；保留当前打开的页签 |
| 聚焦中央表区 | `Alt+Space` | 当前页面的中央内容区 |
| 聚焦通知 | `Alt+N` | 当前窗口；进入时定位最新通知，再按返回原焦点 |
| 关闭当前通知 | `Alt+X` | 通知区聚焦时作用于光标所在通知；否则作用于最新通知 |
| 关闭全部通知 | `Alt+Shift+X` | 关闭当前窗口的全部通知，后台任务继续运行 |

区域边界和键盘光标使用主题 focus ring；按住 Alt 时，各可见区域显示 `L / V / T / Space / N` 提示，关闭目标显示 `X`，通知区显示 `Shift+X`。提示、tooltip 和快捷键帮助读取同一动作绑定，不自行拼接快捷键。列配置使用 `Alt+Shift+V`。

通知出现不抢焦点，新增通知不移动已有光标。通知区的上下键不传给背后的表格；关闭后选择邻近通知，最后一条消失后恢复原焦点。`Esc` 离开通知区并保留消息；侧栏区域的 `Esc` 返回中央表区。区域切换与通知操作不在模态对话框后面执行。没有通知时相应动作不转移焦点；关闭消息只隐藏反馈，不意味着取消任务。

### 对话框动作

所有模态对话框共用同一组键帽。它们只在对话框的 `Dialog` 上下文中注册，文件工作区、设置页和终端都不响应。

| 动作 | 默认键帽 | 作用域 |
| --- | --- | --- |
| `dialog.confirm` | <kbd>Alt</kbd> <kbd>A</kbd>；同时保留 <kbd>Enter</kbd> | 打开的对话框；执行主操作 |
| `dialog.cancel` | <kbd>Alt</kbd> <kbd>C</kbd>；同时保留 <kbd>Esc</kbd> | 打开的对话框；执行取消或关闭 |

主操作按钮的图标与短文案由调用方提供，取消按钮固定使用叉号与普通款；危险确认只把主操作换成危险色。对话框底部按钮的悬停提示沿用同一 Badge 显示实际绑定，不另写快捷键字符串。

`Alt` 组合先由对话框消费，不写入输入框，也不触发对话框后面的工作区快捷键。主操作失败（如表单校验不通过）时对话框保持打开；取消继续走对话框原有的取消回调，包括结束进行中的拖拽，不绕过它。

### 页签切换

`Ctrl+Tab` 立即切换到下一个页签，`Ctrl+Shift+Tab` 反向切换。`Ctrl+1`–`Ctrl+9` 直接选择侧栏中第 1–9 个文件页签。位置导航不再绑定字母快捷键。

侧栏位置是导航按钮：普通点击在当前页签打开，Ctrl/Cmd+单击创建新页签。所有位置均参与该页签的前进／后退历史；页签编号包含显示特殊位置的页签。关闭最后一个页签后新建 Home 页签。`Esc` 用于局部取消。页签行在悬停或按住 Ctrl 时显示关闭按钮；收起时用右上角小 X，悬停提示名称与路径或位置名称。

<kbd>Alt</kbd> <kbd>M</kbd>（兼容 <kbd>F10</kbd>）与左上菜单按钮是同一个动作、同一份菜单：鼠标与按键只驱动一个打开状态，不会叠出第二份菜单；按住 <kbd>Alt</kbd> 时按钮右上角角标显示 `M`，tooltip、菜单右列与设置页显示主键 <kbd>Alt</kbd> <kbd>M</kbd> 而不是兼容键 <kbd>F10</kbd>，<kbd>F10</kbd> 不含修饰键，因此不进入 Ctrl / Alt 任一组提示。菜单在普通文件页和固定特殊页签中共用，提供设置、卷管理和关于，日志仅在启用时出现；设置中心自身仍用左上返回入口。路径编辑或模态对话框期间不打开背景主菜单；筛选词随输入即时保存，不因菜单开合丢失。`Esc` 关闭菜单并把焦点交回工作区，但不退出其所在的特殊页签。

<kbd>F2</kbd> 重命名使用独立输入对话框：初值选中完整文件名，输入框或对话框聚焦时文件快捷键不触发；<kbd>Enter</kbd> 提交，<kbd>Esc</kbd> 取消，同名目标不覆盖。只允许单选，多选不伪造批量重命名。

<kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>V</kbd> 与标题栏列配置按钮共用同一动作，列配置对话框已打开时不会再打开第二个；<kbd>Ctrl</kbd> <kbd>D</kbd> 只在文件工作区、当前文件夹已加载且没有进行中的导航时生效，设置、集合、路径 / 筛选编辑框与对话框保持既有焦点保护。星标与 <kbd>Ctrl</kbd> <kbd>D</kbd> 是同一动作：未收藏时显示“收藏当前位置”、已收藏时显示“取消收藏”，两种状态都附 <kbd>Ctrl</kbd> <kbd>D</kbd>，快捷键帮助里写“收藏 / 取消收藏”而不是只写收藏。

## 2. 公共 ShortcutBadge

每个物理按键使用一枚紧凑、独立的 `kbd` 键帽。组合键是一组键帽，不是包含整段 `Ctrl+N` 的长胶囊。

- 单枚键帽高 **22 px**、最小宽 **22 px**、圆角 **4 px**；键帽之间间距 **4 px**。长键名允许加宽，不能把 `Shift`、`Enter` 等缩成含糊缩写。
- 整组按键不拆行。空间不足时扩展提示或菜单布局，而不是把一个组合键折到两行。
- 修饰键排序固定为 **Ctrl → Alt → Shift → 主键**。Linux 使用 `Ctrl`、`Alt`、`Shift`，不混用 macOS 的 ⌘、⌥ 等符号。
- 键帽之间只有间距，**不插入裸 `+` 号或斜杠分隔符**。如果真正绑定的是加号键，它本身占一枚 <kbd>+</kbd> 键帽；不能把分隔符误读成额外按键。本文表格中的 `/` 只用于区分多个独立动作，不属于组合键显示。
- 使用公共语义色：例如 `surface.control` 背景、`text.secondary` 前景和 `border.subtle` 轻描边。保持可读性，但不抢动作、选中或焦点的强调色，不使用醒目的彩色按键装饰。
- 按钮 tooltip、菜单右侧快捷键列和“帮助 → 快捷键”都调用**同一个 Badge**，共用尺寸、键名格式和间距。菜单右列 / 帮助绑定列统一对齐，不逐项手写偏移；对话框底部按钮的悬停提示也用同一 Badge 显示 `Alt+A` / `Alt+C`。

## 3. 按钮 tooltip

统一结构为**左侧短动作名，右侧组合键 Badge**。必要的原因或补充说明放在次行，不把工具提示写成长段帮助文档。

- 鼠标稳定悬停 **400 ms** 后显示；键盘聚焦时及时显示，不要求用户再等待悬停计时。
- 鼠标离开触发区、焦点离开、点击或 `Esc` 时关闭；点击后取消待触发计时，不能在动作已经执行后迟到弹出。
- tooltip 不透明，主题切换只改变其语义配色。底部控件优先向上显示，靠边时在应用框架范围内避让边缘；不得覆盖触发按钮或挡住用户继续点击它，也不同时显示原生 `title` 提示。
- tooltip 不抢焦点，也不包含必须进入才能完成动作的交互。短动作名使用 Fluent 文案；键帽由绑定数据生成。
- 禁用动作说明必要的禁用原因；tooltip 可解释状态，但不能使禁用控件重新可执行。
- 菜单项禁用时，描述文字与快捷键键帽一起降低强调度；没有快捷键的菜单项也呈现相同的文字禁用效果。
- 未绑定动作只显示动作名和必要说明，不虚构默认键。帮助绑定列可明确显示“未绑定”，不画一枚假的按键。
- **显示的绑定必须与按钮的实际目标一致。** 例如关闭非活动文件标签的按钮不能显示 <kbd>Ctrl</kbd> <kbd>W</kbd>，让人误以为该快捷键会关闭鼠标下的标签。聚焦终端页签栏时，文件标签按钮也不能借用当前终端 scope 的绑定。无法确认目标一致时省略 Badge，而不是改变键盘分发目标。

动态动作名也要对应状态，例如“显示终端 / 收起终端”“展开侧栏 / 折叠侧栏”；它们仍引用同一个 toggle 动作的有效绑定。终端显示开关只保留底栏一份，不在 dock 标题栏复制；显示状态同时由 toggle 选中态表达，隐藏只改变布局、不结束 shell。

终端标题、完整启动路径和运行状态属于内容提示，不塞进动作名。使用公共有界详情提示，标题与路径、状态分层换行，长路径和错误 token 可折行、超高内容内部滚动。展开终端行的关闭控件平时隐藏，行 hover 时显示；导航作用域的有效 Ctrl 提示只揭示活动实例的关闭目标，终端输入聚焦时也显示活动实例的 `Ctrl+W` 提示。关闭控件的槽宽恒定，显隐不改变标题可用宽度；点击非活动行的关闭按钮不先选择该行。

### 按住修饰键的功能提示

按住 <kbd>Ctrl</kbd> 或 <kbd>Alt</kbd> 时，当前界面里**确实已有绑定**的控件显示紧凑单片标签，例如 `R`、`Shift+Tab`、`A`，松开立即消失，不要求先悬停。两个修饰键各成一组：按 <kbd>Ctrl</kbd> 只显示绑定带 Ctrl 的控件，按 <kbd>Alt</kbd> 只显示绑定带 Alt 的控件，没有对应修饰键的 <kbd>F2</kbd> / <kbd>Delete</kbd> / <kbd>F5</kbd> 不因按住修饰键而出现。标签只省略已按住的修饰键前缀，保留 <kbd>Shift</kbd> 和实际按键：`Ctrl+R` 显示 `R`，`Ctrl+Shift+Tab` 显示 `Shift+Tab`，`Alt+A` 显示 `A`。键名仍来自 ShortcutBadge 的同一份键名来源，不另写映射；tooltip、菜单和帮助绑定列继续显示完整组合，如 `Ctrl+R`、`Alt+A`。Ctrl+Alt（以及 AltGr 上报的这个组合）不属于任何一组，此时不显示标签，也不改变按键分发。

- 标签锚点按控件类型分开：图标按钮的标签是**右上角角标**，锚点在该按钮内部角落；NavItem 图文行放在**本行尾部**，折叠成图标时改为右上角角标；文件页签行把页签切换标签放在关闭控件之前的行尾空间，与关闭按钮的 `W` 角标各占一处；文字按钮平时不为提示预留空间；按住对应的 Ctrl / Alt 时，文字末尾的标签与间距在 140 ms 内展开，按钮随之平滑变宽。松开后按相同动画收起；标签按实际文字宽度与字号测量，不覆盖按钮文案或危险确认中的数量。禁用动画时立即切换。
- **Ctrl 提示：**页签显示直接选择的数字 `1`–`9`，相邻页签可显示 `Tab` / `Shift+Tab`；位置导航不显示字母快捷键。松开 Ctrl 或失焦清除提示。
- 设置页的上一项 / 下一项仍在相邻导航行显示；模态只显示自身可用操作。页签顺序、首尾循环与按键分发共用同一份目标数据；两个文件页签时，Ctrl 预览层的两个循环提示可并排落在同一目标行，只有一个时不显示无效循环。
- 标签按**当前焦点作用域**解析绑定：对话框打开时只显示该对话框自己的 `Alt+A` / `Alt+C`，不把后面的工作区快捷键当成可用提示；禁用控件、当前作用域下解析不到绑定的控件、以及绑定不含所按修饰键的控件都不显示。
- 标签紧贴对应控件的角落 / 行尾，必要时略作偏移避开相邻标签；窗口边缘允许贴边调整，但不把标签挪到远处。标签本身不拦截点击、不抢焦点：文字按钮的提示在布局内动画展开，其它控件的标签是绝对定位的浮层；滚动、字体缩放和窗口高度变化后跟随控件，模态内标签位于遮罩之上。
- 松开修饰键或失去窗口激活（包括在窗口外松开）即清除，不残留。输入框与下拉框保持原有焦点和编辑行为，`Ctrl` / `Alt` 组合照常分发，不把字母写入输入、不覆盖 `Enter` / `Esc`、文件选择和拖拽取消。

## 4. 焦点与 scope 契约

| 当前焦点 / 场景 | 分发约定 |
| --- | --- |
| 文件工作区或文件页签栏 | `tab.new` 新建文件页签；`tab.close` 关闭当前活动文件页签，不取鼠标悬停目标。文件标签与窗口终端集合独立，关闭文件标签不结束终端。`panel.details`（Ctrl+P）只在文件工作区切换详情栏，设置与集合页不响应。 |
| 终端半区（页签、标题栏与文本输入） | 同一 `tab.new` 创建终端页签；`tab.close` 结束当前活动终端页签并等待清理，不弹确认。不会误关外层文件标签。 |
| 终端文本输入区 | **Ctrl+N / Ctrl+W 新建／关闭终端页签**；Ctrl+B / L / C、Tab / Shift+Tab 保留给 shell / 前台程序。Tab 不触发 Kit Root 焦点遍历，终端外仍正常遍历。 |
| 路径、搜索等编辑框 | 输入组件原生编辑快捷键不改；不得为了文件动作覆盖其编辑行为。未被输入组件消费的动作才按有效 scope 处理。 |
| 设置中心 | `Ctrl+Tab` / `Ctrl+Shift+Tab` 按侧栏顺序双向循环设置页，首尾相接；不切换背后的文件标签。设置不是可关闭的文件页签，Ctrl+N / W 不在背后新建或关闭文件标签。使用 `Esc` 或左上 ArrowLeft 返回文件浏览；若子控件正在编辑 / 有临时浮层，先处理局部取消。偏好已即时应用，返回不是提交或撤销已生效修改。 |
| 模态对话框 | `Alt+A` / `Enter` 执行主操作，`Alt+C` / `Esc` 取消；这些键只在对话框层匹配，输入框聚焦时也不写入字符，不落到后面的工作区。 |

**显式窗口级动作包括 Ctrl+,、Ctrl+反引号及通知访问键。** 前两项在终端文本或编辑框聚焦时仍由窗口处理：前者到达完整设置中心，后者切换整个终端 dock，包括左侧会话页签。通知的 `Alt+N / Alt+X / Alt+Shift+X` 在文件和设置页共用，模态对话框仍优先。各区域访问键只在相应工作区存在时生效，不把它们误路由成文件标签操作。

收起仍持有焦点的区域后，把焦点移回仍可见的触发控件或文件工作区，不能把焦点留在隐藏终端里。普通页面不会因为鼠标悬停某个按钮而切换键盘 scope。

终端输入使用真实 PTY；Tab / Shift+Tab 送给前台程序，不触发 Root 焦点遍历。完整按键重映射编辑器尚未实现。

## 5. 数据只有一个来源

应用动作记录提供 **语义 action ID + 有效 binding + scope**，经公共 `Shortcut` / `ShortcutBadge` 供以下四处共同消费。公共动作注册表仅保留通知访问、关闭和取消；Files 的文件／卷／页签动作与 Agents 的会话动作各自留在应用内：

```text
当前应用的动作与有效绑定
  ├─ 按键分发：解析焦点、作用域、目标与启用状态
  ├─ 按钮 tooltip：动作名 + 对应目标的绑定 Badge
  ├─ 菜单：动作项 + 统一右侧快捷键列
  └─ 帮助 → 快捷键：动作、有效绑定、作用域
```

控件不能各自硬编码展示字符串。绑定变更时，按键分发、tooltip、菜单和帮助页必须同时读到新绑定；不能只改提示而仍执行旧键，也不能保留未明确设计的隐藏别名。启用状态与目标解析属于动作消费过程，不由 Badge 自己猜测。

对话框的 `Alt+A` / `Alt+C` 也来自同一份绑定数据：启动时只在 `Dialog` 作用域注册一次，按钮、帮助页和 tooltip 都读取它，不按对话框各写一份。

应用使用明确的动作集合和绑定数据，不构建插件系统、通用配置语言或完整重映射编辑器。快捷键为只读参考，集中在独立帮助页中；设置中心只保留可修改的配置。`F1` 与应用菜单的“帮助”打开同一个页，`Ctrl+,` 仍进入设置中心。

帮助和设置都覆盖当前主窗口的工作区。公共 `ui::page::stack` 保存页面和返回焦点；返回按钮、`Esc`、`Alt+Left` 和 `Ctrl+W` 逐层返回，不关闭底下的工作区。例如从设置打开帮助，第一次返回恢复设置页面与焦点，第二次返回恢复原工作区。重复打开同一页不累积重复条目。

## 6. 无障碍与标点键

控件名称使用短动作名，不把说明、完整路径和快捷键全部塞进名称。逗号与反引号分别使用独立键帽，组合键保留清楚的修饰键顺序和读法。无绑定或目标不匹配的按钮不显示虚构按键；原生可访问语义以 GPUI 的实际支持为准。

## 共享实现入口

`gds::ui::Shortcut` 根据应用提供的 Action 与作用域查询实际绑定，`ShortcutBadge`、tooltip 与 `keytips` 复用同一解析和键名格式。应用只维护自己的动作和绑定；没有绑定时只显示动作名。动态输入偏好仍由输入组件按当前配置决定，不把业务动作注册到公共库。

Files 与 Agents 共用 `keytips` 根提示层。`ui::button::Button::tooltip_with_shortcut` 同时登记悬停提示和修饰键提示；已有独立提示内容的按钮可用 `shortcut` 登记，输入区、会话行等自定义控件通过 `keytips::Anchor` 登记。禁用或加载中的按钮不登记提示；窗口失去激活时由公共层清除提示，避免松键事件在窗口外丢失后残留。

Agents 的搜索、新会话、侧栏、窗口模式、对话滚动、输入区、发送/排队和展开编辑器均读取实际动作绑定。展开与收起的侧栏都在下一/上一会话旁显示 `Tab` / `Shift+Tab`，目标与 Ctrl+Tab 的过滤及排序共用同一导航解析；非当前会话的归档按钮只执行点击目标，不借用当前会话的 Ctrl+W 提示。设置导航和弹窗沿用公共控件的同一提示机制。Ctrl 与 Alt 分组显示、混合按键不显示、弹窗焦点屏蔽背景提示的规则与 Files 相同。

按钮提示及富提示中的快捷键行统一使用 `gds::ui::ShortcutHint`：左侧为动作名称，右侧为同一组键帽。Fluent 动作名不内嵌 `Ctrl+…` 等按键文字。已有绑定使用 `ShortcutHint::new`；输入模式决定的绑定使用 `binding`；Ctrl + 点击、Alt + 滚动等手势使用 `gesture`，同样复用键帽。时间轴预览的正文仍可展示时间和内容，所有操作提示行采用这一组件。

长路径、错误与外部文本的提示使用 `gds::ui::tooltip`：宽高受当前窗口约束，保留文字和字体回退，长 token 按字素增加换行机会。通知的 Alt+N / Alt+X / Alt+Shift+X 只操作当前窗口队列，窗口关闭后不转移焦点或通知到其它窗口。

帮助页使用主内容区的背景与透明度；快捷键按操作区域分章节，章节采用大标题。只显示动作名与实际键帽，不附加操作教程或提示段落。

Files 的列表和网格中，PgUp / PgDn 按可见行数翻页，Home / End 到首尾。Ctrl+Shift+N 新建文件夹。Ctrl+N / Ctrl+W 按焦点所在半区新建／关闭文件或终端页签。拖入终端的文件按逐个引用的路径粘贴，不附带回车。

终端默认启用；设置中的终端页排在文件配置之后，可停用终端入口，也可逐行编辑 Shell 参数。停用会隐藏终端面板和入口，保留已有会话；重新启用后可再次展开。
